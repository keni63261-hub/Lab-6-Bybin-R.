Для правильной работы этой лабораторной работы добавьте все эти файл в одну папку с названием iris-fastapi.
После чего в терминале введите pip install -r requirements.txt чтобы скачать все нужные библиотеки.
Для запуска в терминале напишите uvicorn main:app --reload и зайдите на сайт http://127.0.0.1:8000
Если файл не работает, то запустите файл train_model.py и повторите сново.
